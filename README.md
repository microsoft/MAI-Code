We are **[Microsoft AI](https://microsoft.ai/)**, building AI that empowers everyone. MAI-Code is our family of in-house coding models developed to make everyday development faster, smarter, and more efficient.

This is the official repo for **MAI-Code** models, where we publish MAI-Code model releases and updates and engage with the developer community on issues and feedback.

## MAI-Code-1-Flash

Microsoft AI's in-house coding model, now generally available across GitHub Copilot. Purpose-built and optimized for Copilot, it delivers fast, low-latency responses for high-volume, iterative agentic coding.

### Highlights

- **Built for developers, not benchmarks** — Trained directly with the GitHub Copilot production harnesses, so it excels at real-world, agentic Copilot workflows.
- **Maximizes value per token** — Adaptive solution length control keeps responses concise, solving harder problems with up to 60% fewer tokens.
- **Fast and low-latency** — Lower cost, better return on token, smoother interactive workflows.

For benchmark results and the full story, see the [announcement blog post](https://microsoft.ai/news/introducingmai-code-1-flash/).

### Pricing

This model is billed at provider list pricing under usage-based billing. See [Copilot's pricing for models and requests](https://docs.github.com/en/copilot/managing-copilot/understanding-and-managing-copilot-usage/understanding-and-managing-requests-in-copilot) for details.

### Enabling access

- **Individual users** can select the model in the model picker in Visual Studio Code and other supported Copilot surfaces.
- **Copilot Enterprise and Copilot Business plan administrators** must enable the MAI-Code-1-Flash policy in Copilot settings before users can access it. See [Managing policies and features for Copilot in your enterprise](https://docs.github.com/en/copilot/managing-copilot/managing-github-copilot-in-your-organization/managing-policies-for-copilot-in-your-organization).
